# Community expectations

Treat contributors and users with respect. Discuss technical decisions with evidence and explain disagreements clearly. Welcome questions from people with different experience levels.

Harassment, discrimination, threats, doxxing, and publishing another person's private information are not acceptable. Do not use issues or pull requests for personal attacks or unrelated promotion.

Maintainers may edit or remove abusive content, limit participation, or close discussions that violate these expectations. Report concerns privately to the repository owner through an available private channel; avoid repeating sensitive material publicly.

These expectations apply to project issues, pull requests, discussions, and other project-managed spaces.
